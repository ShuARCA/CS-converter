# ココフォリア キャラクターシート変換ツール (CoC6版用)

クトゥルフ神話TRPG（6版）のキャラクターシートURLから、オンラインセッションツール「ココフォリア」でそのまま貼り付け（Ctrl+V）可能なキャラクター駒データ（JSON）を生成するWebアプリケーションです。

## 特徴
- **完全サーバーレス**: ブラウザ上で動作し、データを外部の独自サーバーに送信しないため安全です。
- **CORS回避**: 3種類の無料CORSプロキシへの自動フォールバックを実装し、安定してキャラクターシート情報を取得します。
- **充実のオプション**: チャットパレットへの初期値技能の追加、回避や目星・聞き耳・図書館などの強制表示、能力値×5の追加、パンチ・キック・頭突きへのダメージ行の自動挿入などに対応しています。

## 対応サービス・入力
- **ココフォリア駒JSON**（いあきゃら等の出力結果）
- **キャラクター保管所**（URL入力）
- **キャラエノ** (6版シート)（URL入力）

---

## 使い方
1. **データの入力**
   - 対応するキャラクターシートサービスのURL、またはココフォリア駒出力のJSONデータを入力欄に貼り付け、「変換する」ボタンを押します。
   - ※いあきゃらのURLを直接入力することはできません。いあきゃら側で出力したJSONデータを貼り付けてください。
2. **オプションの設定**
   - チャットパレットに出力する内容やステータスの非公開設定、駒のサイズ、チャットカラーなどのオプションを調整します。
3. **プレビューの確認**
   - パースに成功すると、キャラクターの能力値、HP/MP/SAN、取得技能が画面にプレビュー表示されます。
4. **JSONデータのコピー・ダウンロード**
   - 変換されたJSONデータが表示されます。
   - 「JSONをコピー」ボタンを押してコピーし、**ココフォリアのルーム画面上で Ctrl + V (Macは Cmd + V)** を押すことで、即座にチャットパレットやステータスが設定されたキャラクター駒が生成されます。
   - 必要に応じて `.json` ファイルとしてダウンロードすることも可能です。

## ローカル開発・動作確認方法

当ツールはブラウザの **ES Modules (`type="module"`)** を使用しているため、セキュリティの制限（CORS制限）によりローカルファイル（`file://`プロトコル）から直接 `index.html` を開くと動作しません。

ローカルで動作確認を行う場合は、必ず以下のように簡易的なHTTPサーバーを立ち上げてアクセスしてください。

### 起動方法の例

#### 方法 1: Node.js (npx) を使用する場合 (推奨)
```bash
npx serve .
```
起動後、ブラウザで `http://localhost:3000` にアクセスしてください。

#### 方法 2: Python3 を使用する場合
```bash
python -m http.server 8000
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。

## テストの実行方法
各パーサーおよびチャットパレット生成処理などの単体テストが用意されています。

1. 上記の方法でHTTPサーバーを立ち上げます。
2. ブラウザで `http://localhost:3000/test/` または `http://localhost:8000/test/` にアクセスします。
3. 画面上にアサーションテストの結果が一覧表示されます。すべて「PASSED」となれば正常です。
